# PRNN-LSTM for Thermal Sterilization

This repository contains the data and code for the manuscript **"A Physics-Regularized Recurrent Neural Network for Thermal Sterilization of Canned Solid-Liquid Food Mixtures."**

It includes the CFD dataset, the PRNN-LSTM training and evaluation code, the model selection studies, the structured holdout tests, and the numerical results reported in the manuscript. The dataset contains **10,526 CFD simulations** of canned peas in water.

## Installation

Python 3.11 or 3.12 is recommended. The manuscript results were obtained with Python 3.12.11, TensorFlow 2.20.0, and Keras 3.13.2.

Create and activate a virtual environment:

```bash
python -m venv .venv

# Linux or macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

Install the required packages:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Dataset

The input dataset is:

```text
dataset/dataset_all.csv
```


## Software check

Before running the full study, a short run can be used to confirm that the complete workflow works:

```bash
python main.py --data dataset/dataset_all.csv --mode check --sample-cases 256 --check-epochs 3 --device gpu --precision mixed_float16
```

The results are written to `outputs_check/`. These results only confirm that the software runs correctly and are not the manuscript results.

## Full study run

Run the complete study with:

```bash
python main.py --data dataset/dataset_all.csv --mode full --device gpu --precision mixed_float16
```

This runs:

- Stages A to D for model selection
- Stage E model comparison
- Final PRNN-LSTM training and test evaluation
- Structured holdout evaluations

Completed runs are saved automatically. If the run is interrupted, run the same command again and compatible completed runs will be reused.

## Outputs

All results are written to `outputs/`. The main numerical results are in:

```text
outputs/results_all.xlsx
```

Additional outputs are stored in:

| Folder | Contents |
| --- | --- |
| `outputs/tables/` | CSV versions of the result tables |
| `outputs/models/` | Trained final model and its settings |
| `outputs/_internal/` | Intermediate files used to resume interrupted runs |

This repository produces the numerical data used in the manuscript. The figure files are not generated by this repository.
